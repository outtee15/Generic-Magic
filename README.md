# Generic Magic

A magic-themed mod for Minecraft built with [Fabric](https://fabricmc.net/) and Java.

> **Status:** Early development. The project currently contains the Fabric mod scaffold; gameplay features are still to come.

## Requirements

- Minecraft `26.3`
- Fabric Loader `>= 0.20.1`
- [Fabric API](https://modrinth.com/mod/fabric-api)
- Java `25`

## Building

```sh
./gradlew build
```

On Windows, use `gradlew.bat build`. The built jar is written to `build/libs/`.

## Development setup

For IDE setup instructions, see the [Fabric documentation](https://docs.fabricmc.net/develop/getting-started/creating-a-project#setting-up).
